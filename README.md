# PROFILE KOTA SUMENEP

Website profil interaktif yang menyajikan informasi mengenai keindahan, sejarah, wisata kuliner, serta destinasi populer di **Kabupaten Sumenep (Keris City)**.

---

## 📌 Fitur Utama Website

Website ini terdiri dari 3 halaman utama:

1. **Profile (`PROFILE.html`)**
   - Menampilkan beranda dengan *hero section/carousel* tempat-tempat ikonik seperti **Selamat Datang Kabupaten Sumenep**, **Masjid Jamik Sumenep**, dan **Soto Sabrang**.
2. **Food (`FOOD.html`)**
   - Menampilkan galeri kuliner khas Sumenep (Soto Sabrang, Sate Madura, dll.).
3. **Destination (`DESTINATION.html`)**
   - Informasi seputar destinasi wisata menarik seperti:
     - Museum Keraton Sumenep
     - Masjid Jamik Sumenep
     - Pantai Lombang
     - Pantai Gili Labak

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Struktur utama website
- **CSS3** - Styling & Tata Letak Responsive
- **JavaScript** - Interaktivitas komponen website
- **Bootstrap** - Framework CSS untuk tampilan terstruktur & menarik
